# vasylian.com

Portfolio of Artur Vasilyan: 8 language versions (`/`, `/lv/`, `/lt/`, `/ee/`, `/pl/`, `/de/`, `/ua/`, `/ru/`), static HTML, no build step on the server.

These files are the **build output**. The source (texts in 8 languages, the project list, screenshot and build scripts)
lives in [vasilyanaptyp-oss/vasylian](https://github.com/vasilyanaptyp-oss/vasylian): change it there, run `node _src/build.cjs`,
and copy `index.html`, the language folders, `404.html`, `sitemap.xml`, `robots.txt` and `assets/` here.
`CNAME` (vasylian.com) and `.nojekyll` belong to this repo only.

Personal link for a cold email: `https://vasylian.com/lv/?c=<project id>` greets the owner and pins their concept first.
